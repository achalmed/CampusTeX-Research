# 08_INVESTIGACION/casos — Casos de estudio (fuente)

> La **documentación fuente** de los casos de estudio: el material bruto (noticias,
> datos, contexto) con el que luego se arma un caso como evaluación.

- **Qué va:** dossier del caso, fuentes, contexto, notas de preparación.
- **Qué NO va:** el caso convertido en **evaluación** (`.tex`) →
  `04_EVALUACIONES/proyectos/`.
- **Nomenclatura:** una subcarpeta por caso: `caso_inflacion_2020/`.

## Ejemplo — carpeta

```
casos/
└── caso_inflacion_2020/
    ├── contexto.md
    ├── fuentes.md
    └── datos_bcrp.csv
```
