# 08_INVESTIGACION/referencias — Bibliografía (.bib)

> Los archivos `.bib` y exportes de Zotero del curso, para citar en documentos LaTeX.

- **Qué va:** `curso.bib`, exportes `.bib` por unidad/tema, colección de Zotero.
- **Origen de verdad:** puede espejar `~/Documents/Academic_Class_Framework/bibliography/`.
  No dupliques la misma referencia en dos `.bib` divergentes.
- **Nomenclatura:** `curso.bib`, `referencias_unidad_03.bib`.

## Ejemplo — `curso.bib`

```bibtex
@book{apa2020,
  author    = {{American Psychological Association}},
  title     = {Publication Manual of the American Psychological Association},
  edition   = {7},
  year      = {2020},
  publisher = {APA}
}
```
