# 08_INVESTIGACION/papers — Artículos de investigación

> Papers de nivel avanzado que sustentan casos, seminarios o profundización (no las
> lecturas básicas del temario).

- **Qué va:** artículos seminales, working papers, literatura para casos avanzados.
- **Qué NO va:** lectura de **una unidad** → `02_CONTENIDO/Unidad_NN/lecturas/`;
  artículo de **apoyo general** → `06_RECURSOS/articulos/`.
- **Nomenclatura:** `autor_año_tema.pdf`: `keynes_1936_teoria_general.pdf`.

## Ejemplo

```
papers/
└── keynes_1936_teoria_general.pdf
```
