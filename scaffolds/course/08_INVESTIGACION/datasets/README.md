# 08_INVESTIGACION/datasets — Datos de investigación

> Bases de datos de **investigación** (crudas y procesadas) que alimentan notebooks y
> casos avanzados.

- **Qué va:** microdatos, series largas, datos crudos + su versión limpia.
- **Qué NO va:** datos **para enseñar** → `06_RECURSOS/datasets/`; datos que
  **resuelven un examen** → `04_EVALUACIONES/.../code/data/`.
- **Nomenclatura:** `snake_case` con año/fuente: `enaho_2023_raw.csv`,
  `enaho_2023_clean.parquet`.

## Ejemplo

```
datasets/
├── enaho_2023_raw.csv
└── enaho_2023_clean.parquet
```
