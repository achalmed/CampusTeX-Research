# 08_INVESTIGACION/notebooks — Notebooks de análisis

> Cuadernos de análisis reproducible: `.ipynb` (Jupyter), `.Rmd`/`.qmd` (R/Quarto).

- **Qué va:** análisis exploratorio, réplicas, generación de figuras de investigación.
- **Qué NO va:** el script que **resuelve una evaluación** → `04_EVALUACIONES/.../code/`.
- **Nomenclatura:** `snake_case`: `analisis_pobreza.ipynb`. Deja el notebook
  **ejecutable** y con rutas relativas a `../datasets/`.

## Ejemplo

```
notebooks/
└── analisis_pobreza.ipynb        ← lee de ../datasets/, exporta figuras
```
