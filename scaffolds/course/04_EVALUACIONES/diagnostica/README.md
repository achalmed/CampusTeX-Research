# diagnostica — Evaluación diagnóstica de entrada

> La evaluación **de entrada** que mide saberes previos al iniciar el curso. No se
> califica para nota; orienta el nivel del grupo.

- **Sigla:** `ED` (examen diagnóstico). El **momento** «diagnóstico» se fija en
  `\tipoevaluacion{Examen Diagnóstico}`; la **estructura** puede ser objetiva o de
  desarrollo, así que se usa la plantilla que corresponda (`02-examen-objetivo` suele
  encajar) y el `.tex` se coloca aquí a mano.
- `new-evaluacion.sh` no tiene destino automático a esta carpeta: crea el examen con
  la plantilla adecuada y **muévelo** aquí.

## Nomenclatura

`AAAAMMDD_ED.tex`. Ej.: `20260317_ED.tex`.

## Ejemplo — carpeta

```
diagnostica/
└── 20260317_ED.tex / .pdf       ← diagnóstico de entrada (no califica para nota)
```
