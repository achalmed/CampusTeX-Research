# 05_ESTUDIANTES/entregas — Consignas y entregas modelo

> Consignas de entrega, formatos exigidos y **entregas ejemplares** que se conservan
> como referencia entre dictados.

- **Qué va:** instrucciones de entrega, plantillas que el alumno rellena, 1–2 trabajos
  modelo anonimizados.
- **Qué NO va:** las entregas **reales** de una promoción → `09_SEMESTRES/<periodo>/evidencias/entregas/`.
- **Nomenclatura:** `_consigna_<trabajo>.md`, `plantilla_<trabajo>.docx`,
  `modelo_<trabajo>.pdf`.

## Ejemplo — carpeta

```
entregas/
├── _consigna_ensayo.md
├── plantilla_ensayo.docx
└── modelo_ensayo_anonimo.pdf
```
