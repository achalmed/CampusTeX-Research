# 05_ESTUDIANTES/retroalimentacion — Formatos de feedback

> Plantillas y guías para dar **retroalimentación** a los estudiantes de forma
> consistente (no la retroalimentación puntual a un alumno real).

- **Qué va:** plantilla de comentarios, banco de comentarios frecuentes, guía de
  feedback formativo.
- **Qué NO va:** la retroalimentación **entregada a un alumno concreto** de un dictado
  → junto a sus notas en `09_SEMESTRES/<periodo>/`.
- **Nomenclatura:** `plantilla_feedback.md`, `banco_comentarios.md`.

## Ejemplo — `plantilla_feedback.md`

```markdown
# Retroalimentación — <trabajo>
**Fortalezas:**
**A mejorar:**
**Sugerencia concreta:**
**Nota:** __ / 20
```
