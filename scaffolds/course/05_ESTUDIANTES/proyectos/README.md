# 05_ESTUDIANTES/proyectos — Enunciados y proyectos ejemplares

> Enunciados de los proyectos del curso y **proyectos modelo** que se conservan como
> referencia de nivel esperado.

- **Qué va:** enunciado/consigna del proyecto, cronograma de hitos, 1–2 proyectos
  ejemplares anonimizados.
- **Qué NO va:** los proyectos **reales** de la promoción →
  `09_SEMESTRES/<periodo>/evidencias/proyectos/`. La evaluación tipo caso/proyecto
  (el `.tex`) → [`04_EVALUACIONES/proyectos/`](../../04_EVALUACIONES/proyectos/README.md).
- **Nomenclatura:** `_enunciado_proyecto.md`, `modelo_proyecto_<tema>.pdf`.

## Ejemplo — carpeta

```
proyectos/
├── _enunciado_proyecto_final.md
└── modelo_proyecto_inflacion.pdf
```
