# 05_ESTUDIANTES/exposiciones — Pautas y modelos de exposición

> Pautas para las exposiciones de los estudiantes y materiales **modelo** (una buena
> presentación de referencia).

- **Qué va:** guía de exposición, plantilla de diapositivas del alumno, rúbrica de
  referencia (la rúbrica formal vive en `01_PLANIFICACION/rubricas/`).
- **Qué NO va:** las exposiciones **reales** de una promoción →
  `09_SEMESTRES/<periodo>/evidencias/exposiciones/`.
- **Nomenclatura:** `_pauta_exposicion.md`, `plantilla_exposicion.pptx`.

## Ejemplo — `_pauta_exposicion.md`

```markdown
# Pauta de exposición (10 min)
1. Problema y objetivo (2 min)
2. Método (3 min)
3. Resultados (3 min)
4. Conclusiones y preguntas (2 min)
Evaluación: rúbrica en 01_PLANIFICACION/rubricas/rubrica_exposicion.md
```
