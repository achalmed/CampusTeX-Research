# 07_MULTIMEDIA/animaciones — Animaciones para clase

> Animaciones cortas (GIF, secuencias) para ilustrar procesos en clase.

- **Qué va:** GIF/animaciones ligeras que ayudan a explicar un concepto dinámico.
- **Qué NO va:** video largo/producido → [`videos/`](../videos/README.md).
- **Nomenclatura:** `snake_case`: `ciclo_investigacion.gif`.

## Ejemplo

```
animaciones/
└── ciclo_investigacion.gif
```
