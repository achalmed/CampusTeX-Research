# 07_MULTIMEDIA — Recursos multimedia del curso

> **Responsabilidad única:** los **activos multimedia transversales** del curso
> (imágenes, diagramas, audio, video, logos) que usan varias sesiones o materiales. Es
> el banco visual del curso; no las figuras de una unidad concreta.

## Subcarpetas

| Subcarpeta | Contiene |
|---|---|
| [`imagenes/`](imagenes/README.md) | fotos, capturas, ilustraciones transversales |
| [`diagramas/`](diagramas/README.md) | esquemas y diagramas (fuente + export) |
| [`animaciones/`](animaciones/README.md) | GIF/animaciones para clase |
| [`audio/`](audio/README.md) | podcasts, narraciones, audio de apoyo |
| [`videos/`](videos/README.md) | video **producido** para el curso |
| [`logos/`](logos/README.md) | logos institucionales y del curso |

## Qué NO va aquí

- Figuras que cita **un tema** del temario → `02_CONTENIDO/Unidad_NN/figuras/`.
- Videos de **referencia externa** (enlaces) → `06_RECURSOS/videos/`.
- Gráficos generados por el **código de una evaluación** → `04_EVALUACIONES/.../code/figures/`.

## Nomenclatura

`snake_case`, sin tildes; prefiere formatos vectoriales para diagramas (`.svg`, `.pdf`).

## Ejemplo — carpeta

```
07_MULTIMEDIA/
├── imagenes/portada_curso.png
├── diagramas/proceso_citacion.svg
└── logos/cau-logo.png
```
