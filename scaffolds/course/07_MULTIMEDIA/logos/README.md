# 07_MULTIMEDIA/logos — Logos institucionales y del curso

> Logos que usan los documentos y diapositivas: universidad, facultad, CAU, curso.

- **Qué va:** logo institucional (`cau-logo.png`), escudos, marca del curso, en varias
  resoluciones/formatos (`.png` transparente, `.svg`, `.pdf`).
- **Nota:** el **logo canónico** del framework vive en `assets/branding/`; los scripts
  copian una **copia local** del logo junto a cada deck (deck autocontenido). Aquí
  guardas las variantes propias del curso.
- **Nomenclatura:** `cau-logo.png`, `unsch-escudo.svg`.

## Ejemplo

```
logos/
├── cau-logo.png
└── unsch-escudo.svg
```
