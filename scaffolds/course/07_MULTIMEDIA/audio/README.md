# 07_MULTIMEDIA/audio — Audio de apoyo

> Audio del curso: narraciones, podcasts, explicaciones grabadas.

- **Qué va:** archivos de audio ligeros o enlaces a episodios/narraciones.
- **Nomenclatura:** `snake_case`: `intro_curso.mp3`.
- **Peso:** para audio largo, enlaza en un índice `.md` en vez de versionar el binario.

## Ejemplo

```
audio/
└── intro_curso.mp3
```
