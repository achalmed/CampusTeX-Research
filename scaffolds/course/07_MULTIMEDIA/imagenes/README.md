# 07_MULTIMEDIA/imagenes — Imágenes transversales

> Fotos, capturas e ilustraciones que usan **varias** sesiones o documentos del curso.

- **Qué va:** imágenes reutilizables (portadas, fotos, capturas de interfaz).
- **Qué NO va:** figura de **un tema** del temario → `02_CONTENIDO/Unidad_NN/figuras/`.
- **Nomenclatura:** `snake_case` descriptivo: `portada_curso.png`, `interfaz_zotero.png`.

## Ejemplo

```
imagenes/
├── portada_curso.png
└── interfaz_zotero.png
```
