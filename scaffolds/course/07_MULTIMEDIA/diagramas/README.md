# 07_MULTIMEDIA/diagramas — Esquemas y diagramas

> Diagramas y esquemas del curso, con su **fuente editable** y su **export**.

- **Qué va:** diagramas de proceso, mapas conceptuales, esquemas. Guarda la fuente
  (`.drawio`, `.svg`, `.tex`/TikZ) junto al export (`.pdf`/`.png`).
- **Nomenclatura:** `snake_case`: `proceso_citacion.svg` + `proceso_citacion.pdf`.
- **Preferencia:** vectorial (`.svg`/`.pdf`) para que escale sin perder nitidez.

## Ejemplo

```
diagramas/
├── proceso_citacion.drawio     ← fuente editable
└── proceso_citacion.svg        ← export para insertar
```
