# 06_RECURSOS/libros — Libros de texto y consulta

> Libros completos de referencia del curso (PDF/ePub).

- **Qué va:** manuales, libros de texto, obras de consulta del curso entero.
- **Qué NO va:** capítulos sueltos de **una unidad** → `02_CONTENIDO/Unidad_NN/lecturas/`.
- **Nomenclatura:** `autor_año_titulo.pdf` en `snake_case`: `apa_2020_manual.pdf`.
- **Peso:** si son grandes, considera enlazarlos (no versionar binarios pesados en Git).

## Ejemplo

```
libros/
├── apa_2020_manual_publicaciones.pdf
└── walpole_2012_probabilidad.pdf
```
