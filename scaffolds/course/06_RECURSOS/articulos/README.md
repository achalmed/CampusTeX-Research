# 06_RECURSOS/articulos — Artículos y papers de referencia

> Papers y artículos de referencia del **curso completo** (no de una unidad puntual).

- **Qué va:** artículos de revista, working papers, informes citados a lo largo del curso.
- **Qué NO va:** lecturas de **una unidad** → `02_CONTENIDO/Unidad_NN/lecturas/`;
  producción **de investigación** del docente → `08_INVESTIGACION/papers/`.
- **Nomenclatura:** `autor_año_tema.pdf`: `acemoglu_2001_instituciones.pdf`.

## Ejemplo

```
articulos/
└── acemoglu_2001_instituciones.pdf
```
