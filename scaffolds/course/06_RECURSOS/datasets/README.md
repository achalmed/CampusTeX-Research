# 06_RECURSOS/datasets — Datos de apoyo a la enseñanza

> Bases de datos usadas **para enseñar** (ejemplos en clase, práctica libre), no para
> calificar una evaluación.

- **Qué va:** datasets de ejemplo, series de práctica, datos para demos en clase.
- **Qué NO va:** datos que **resuelven un examen** → `04_EVALUACIONES/.../code/data/`
  (con el nombre estándar `data.xlsx`); datos de **investigación** →
  `08_INVESTIGACION/datasets/`.
- **Nomenclatura:** descriptiva en `snake_case`: `pbi_peru_2000_2024.csv`.

## Ejemplo

```
datasets/
├── pbi_peru_2000_2024.csv
└── notas_ejemplo.xlsx
```
