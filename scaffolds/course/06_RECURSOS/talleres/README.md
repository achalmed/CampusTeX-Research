# 06_RECURSOS/talleres — Material de talleres

> Material de **talleres** y sesiones prácticas complementarias (fuera de la secuencia
> normal de `03_SESIONES`): guías paso a paso, hojas de trabajo, retos.

- **Qué va:** guías de taller, hojas de ejercicios guiados, material de refuerzo.
- **Qué NO va:** las diapositivas de una sesión regular → `03_SESIONES/SNN/02_Clase/`;
  la práctica **calificada** → `04_EVALUACIONES/practicas/`.
- **Nomenclatura:** `taller_NN_<tema>.md/.pdf`: `taller_01_zotero.md`.

## Ejemplo

```
talleres/
└── taller_01_zotero.md
```
