# 06_RECURSOS/software — Software y guías de instalación

> Instaladores, scripts de setup y guías para instalar el software del curso (R,
> Python, Stata, EViews, LaTeX…).

- **Qué va:** guías de instalación, scripts de configuración, listas de paquetes.
- **Qué NO va:** binarios propietarios pesados o con licencia (enlázalos, no los
  versiones).
- **Nomenclatura:** `instalar_<software>.md`, `requirements.txt`, `setup_<x>.sh`.

## Ejemplo — `instalar_r.md`

```markdown
# Instalar R + RStudio
1. Descargar R desde CRAN (enlace).
2. Instalar RStudio Desktop.
3. Paquetes: install.packages(c("tidyverse","stargazer","fixest"))
```
