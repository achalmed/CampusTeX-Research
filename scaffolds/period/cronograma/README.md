# cronograma — Calendario real del dictado

> El calendario **tal como ocurrió** este semestre: fechas efectivas de cada sesión,
> exámenes y entregas (con sus ajustes por feriados, paros, etc.).

- **Qué va:** `cronograma_AAAA-ciclo.md`/`.xlsx` con semana → fecha → sesión/evaluación.
- **Qué NO va:** el calendario **modelo** del curso → `00_ADMINISTRACION/calendario.tex`.

## Ejemplo — `cronograma_2026-I.md`

```markdown
# Cronograma 2026-I
| Semana | Fecha      | Sesión / Evaluación        |
|:------:|------------|----------------------------|
|   1    | 2026-03-17 | S01 Introducción           |
|   8    | 2026-05-05 | Examen Parcial (20260505_EP)|
|  16    | 2026-07-16 | Examen Final (20260716_EF) |
```
