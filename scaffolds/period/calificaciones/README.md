# calificaciones — Notas del dictado

> El **registro de notas** de esta promoción: parciales, prácticas, final, promedio.

- **Qué va:** `notas.xlsx`/`.csv` con las calificaciones por instrumento y el promedio.
- **Qué NO va:** el acta **oficial** firmada → `00_ADMINISTRACION/` del curso; los
  exámenes en sí → [`../evaluaciones_aplicadas/`](../evaluaciones_aplicadas/README.md).
- **⚠ Datos personales:** no publicar.

## Ejemplo — `notas.csv`

```csv
codigo,parcial,practicas,final,promedio
```
