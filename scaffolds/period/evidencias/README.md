# evidencias — Trabajo real de los estudiantes

> Las **evidencias de aprendizaje** de esta promoción: lo que los estudiantes
> realmente entregaron, expusieron y proyectaron. Sirve de respaldo académico y para
> la acreditación.

## Subcarpetas

| Subcarpeta | Contiene |
|---|---|
| [`entregas/`](entregas/README.md) | tareas y trabajos entregados |
| [`exposiciones/`](exposiciones/README.md) | material de las exposiciones dadas |
| [`proyectos/`](proyectos/README.md) | proyectos finales de la promoción |

## Qué NO va aquí

- Los **modelos/ejemplares** atemporales → `05_ESTUDIANTES/` del curso.
- **⚠ Datos personales:** contiene trabajo identificable de estudiantes; anonimiza
  antes de reutilizar como ejemplo.

## Ejemplo — carpeta

```
evidencias/
├── entregas/20231001_garcia_tarea05.pdf
├── exposiciones/grupo_03_citacion.pdf
└── proyectos/20231001_garcia_proyecto_final.pdf
```
