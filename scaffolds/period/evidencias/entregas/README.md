# evidencias/entregas — Tareas y trabajos entregados

> Los archivos que los estudiantes **entregaron** en este dictado (tareas, informes).

- **Qué va:** entregas reales, una por estudiante/trabajo.
- **Nomenclatura sugerida:** `<codigo>_<apellido>_<trabajo>.pdf` →
  `20231001_garcia_tarea05.pdf`.
- **⚠ Datos personales:** no publicar; anonimizar si se comparte como modelo.

## Ejemplo

```
entregas/
├── 20231001_garcia_tarea05.pdf
└── 20231002_quispe_tarea05.pdf
```
