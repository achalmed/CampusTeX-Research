# evidencias/proyectos — Proyectos finales de la promoción

> Los **proyectos finales** que entregó esta promoción.

- **Qué va:** el proyecto completo de cada estudiante/grupo (informe + anexos).
- **Qué NO va:** el **enunciado** del proyecto → `05_ESTUDIANTES/proyectos/` del curso;
  el proyecto como **evaluación** (`.tex`) → `04_EVALUACIONES/proyectos/`.
- **Nomenclatura sugerida:** `<codigo>_<apellido>_proyecto.pdf` o `grupo_NN_proyecto.pdf`.
- **⚠ Datos personales:** anonimizar si se reutiliza como ejemplo.

## Ejemplo

```
proyectos/
└── 20231001_garcia_proyecto_final.pdf
```
