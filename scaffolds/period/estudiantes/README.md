# estudiantes — Matrícula de la promoción

> La **lista de estudiantes** matriculados en este dictado.

- **Qué va:** `lista.csv`/`.xlsx` con código, apellidos, nombres, correo, condición.
- **Qué NO va:** trabajos de los estudiantes → [`../evidencias/`](../evidencias/README.md);
  notas → [`../calificaciones/`](../calificaciones/README.md).
- **⚠ Datos personales:** no publicar.

## Ejemplo — `lista.csv`

```csv
codigo,apellidos,nombres,correo,condicion
```
