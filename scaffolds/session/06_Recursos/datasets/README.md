# 06_Recursos/datasets — Datos de la sesión

> Datasets **pequeños** que usa esta sesión (demo en clase o la actividad).

- **Qué va:** CSV/xlsx ligeros para la clase.
- **Qué NO va:** datos para **calificar** (van a `04_EVALUACIONES/.../code/data/` con el
  nombre estándar `data.xlsx`); datos grandes de curso → `06_RECURSOS/datasets/`.
- **Nomenclatura:** `snake_case` descriptivo: `ejemplo_citas.csv`.

## Ejemplo

```
datasets/
└── ejemplo_referencias.csv
```
