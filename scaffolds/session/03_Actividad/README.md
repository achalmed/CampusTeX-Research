# 03_Actividad — Actividad práctica en clase

> El material de la **actividad que se hace durante la clase**: hoja de ejercicios
> guiados, dinámica grupal, guía de laboratorio corta.

## Qué va aquí

- Hoja de trabajo de la actividad, instrucciones, plantillas para el alumno.
- Datos pequeños de la actividad (si son grandes → [`06_Recursos/datasets/`](../06_Recursos/README.md)).

## Qué NO va aquí

- La **evaluación calificada** de salida → [`04_Evaluacion/`](../04_Evaluacion/README.md).
- Una práctica calificada formal → `04_EVALUACIONES/practicas/` del curso.

## Ejemplo — `actividad.md`

```markdown
# Actividad — Identificar citas APA (20 min, en parejas)
1. Lean el párrafo dado.
2. Marquen las 3 citas y clasifíquenlas (directa/parafraseada).
3. Corrijan la que está mal formateada.
```
