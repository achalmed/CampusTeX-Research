# course/syllabus/

Syllabus oficial del curso.

- `syllabus.md` — documento maestro del curso (20 clases): temario completo,
  metodología, cronograma. Fuente de contenido para planificar sesiones.
- `syllabus.tex` — versión imprimible (compila con **lualatex** usando la
  clase vendorizada `yaac-luatex.cls`; existe variante `yaac-xelatex.cls`).
  Las fuentes Source Sans Pro necesarias están en `fonts/`.
- `temario_completo.pdf` — temario compilado.

Compilar: `~/Documents/scripts_for_latex/script_compilar_latex/main.sh course/syllabus/syllabus`
