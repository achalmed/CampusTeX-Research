\section{Formato del Documento}

El trabajo monográfico debe cumplir con los siguientes requisitos formales:

\subsection{Especificaciones Generales}

\begin{itemize}
  \item \textbf{Extensión:} Entre 20 y 25 páginas, excluyendo referencias bibliográficas y anexos.
  \item \textbf{Tipo de letra:} Times New Roman, tamaño 12 puntos.
  \item \textbf{Interlineado:} Doble espacio en todas las partes de un documento.
  \item \textbf{Márgenes:} Use 1 pulgada (2.54 cm).
  \item \textbf{Numeración de páginas:} En la esquina superior derecha.
\end{itemize}

\begin{warningbox}{$\triangle$ Importante}
  El cumplimiento estricto de estas especificaciones es fundamental para la evaluación del trabajo. Documentos que no cumplan con el formato establecido podrán ser devueltos para corrección.
\end{warningbox}

\section{Estructura del Trabajo}

El trabajo debe organizarse siguiendo la estructura propuesta en el índice generado con ChatGPT y el prompt enseñado en clases. A continuación se presenta el esquema de referencia:

\subsection{Componentes Obligatorios}

\begin{enumerate}
  \item \textbf{Portada}
  \begin{itemize}
    \item Debe incluir: título del trabajo, nombre del autor, curso, institución y fecha.
  \end{itemize}
  
  \item \textbf{Índice}
  \begin{itemize}
    \item Refleja la estructura completa del trabajo.
    \item Numeración jerárquica según formato APA Séptima Edición.
  \end{itemize}
  
  \item \textbf{Introducción}
  \begin{itemize}
    \item Presentación clara del tema investigado.
    \item Definición de objetivos generales y específicos.
    \item Justificación de la relevancia del tema.
  \end{itemize}
  
  \item \textbf{Desarrollo}
  \begin{itemize}
    \item Contenido organizado según el índice propuesto.
    \item Análisis profundo y fundamentado del tema.
    \item Uso adecuado de fuentes bibliográficas.
  \end{itemize}
  
  \item \textbf{Conclusiones y Recomendaciones}
  \begin{itemize}
    \item Síntesis de los principales hallazgos.
    \item Reflexiones críticas sobre el tema investigado.
    \item Sugerencias prácticas y aplicables.
  \end{itemize}
  
  \item \textbf{Referencias Bibliográficas}
  \begin{itemize}
    \item Formato APA Séptima Edición.
    \item Inclusión de todas las fuentes citadas en el documento.
    \item Orden alfabético por apellido del autor.
  \end{itemize}
  
  \item \textbf{Anexos}
  \begin{itemize}
    \item Material adicional que complemente el trabajo.
    \item Gráficos, tablas, cuestionarios u otros recursos relevantes.
  \end{itemize}
\end{enumerate}

\section{Aspectos Formales}

\subsection{Calidad de Redacción}

  \item \textbf{Lenguaje formal:} Redacción académica, evitando coloquialismos y expresiones informales.
  \item \textbf{Coherencia y cohesión:} Textos bien estructurados con ideas conectadas lógicamente.
\end{itemize}

\subsection{Citas y Referencias}

\begin{itemize}
  \item \textbf{Citas directas e indirectas:} Uso correcto según normas APA Séptima Edición.
  \item \textbf{Documentación completa:} Todas las referencias deben estar debidamente registradas.
  \item \textbf{Variedad de fuentes:} Se recomienda consultar libros, artículos académicos, bases de datos especializadas y fuentes confiables.
\end{itemize}

\end{warningbox}

\section{Recomendaciones Adicionales}

Para garantizar la calidad de su trabajo monográfico, considere las siguientes recomendaciones:

\subsection{Durante la Investigación}

\begin{enumerate}
  \item \textbf{Consultar bibliografía actualizada y confiable}
  \begin{itemize}
    \item Priorizar artículos académicos revisados por pares.
    \item Utilizar bases de datos especializadas (JSTOR, SciELO, Google Scholar).
    \item Verificar la vigencia de la información consultada.
  \end{itemize}
  
  \item \textbf{Organizar la información desde el inicio}
  \begin{itemize}
    \item Crear un sistema de fichas bibliográficas.
    \item Utilizar gestores de referencias (Zotero, Mendeley, EndNote).
    \item Mantener un respaldo digital de todos los documentos consultados.
  \end{itemize}
  
  \item \textbf{Planificar el tiempo adecuadamente}
  \begin{itemize}
    \item Establecer un cronograma personal de trabajo.
    \item Distribuir el tiempo entre investigación, redacción y revisión.
    \item Dejar tiempo suficiente para correcciones y ajustes.
  \end{itemize}
\end{enumerate}

\subsection{Durante la Redacción}

\begin{enumerate}
  \item \textbf{Escribir borradores preliminares}
  \begin{itemize}
    \item No buscar la perfección en el primer intento.
    \item Revisar y mejorar progresivamente el contenido.
    \item Solicitar retroalimentación de compañeros o docentes.
  \end{itemize}
  
  \item \textbf{Citar correctamente desde el principio}
  \begin{itemize}
    \item Evitar el plagio involuntario citando adecuadamente.
    \item Parafrasear ideas ajenas con rigor académico.
    \item Distinguir claramente entre ideas propias y ajenas.
  \end{itemize}
  
  \item \textbf{Mantener coherencia en el estilo}
  \begin{itemize}
    \item Usar consistentemente el mismo tiempo verbal.
    \item Aplicar el formato APA de manera uniforme.
    \item Verificar la concordancia gramatical en todo el texto.
  \end{itemize}
\end{enumerate}

\subsection{Antes de la Entrega}

\begin{enumerate}
  \item \textbf{Revisar exhaustivamente el trabajo}
  \begin{itemize}
    \item Leer el documento completo varias veces.
    \item Verificar ortografía y gramática (herramientas: Grammarly, LanguageTool).
    \item Confirmar que todas las citas tengan su referencia correspondiente.
    \item Asegurar que el índice refleje exactamente el contenido.
  \end{itemize}
  
  \item \textbf{Verificar el cumplimiento de lineamientos}
  \begin{itemize}
    \item Comprobar extensión, márgenes, tipo de letra y espaciado.
    \item Confirmar que todos los componentes obligatorios estén incluidos.
    \item Revisar la calidad de impresión y encuadernado (versión física).
    \item Probar que el archivo PDF se abre correctamente (versión digital).
  \end{itemize}
  
  \item \textbf{Solicitar asesoría al docente}
  \begin{itemize}
    \item No dudar en consultar dudas específicas.
    \item Solicitar orientación sobre la estructura o contenido.
    \item Pedir retroalimentación sobre borradores preliminares.
  \end{itemize}
\end{enumerate}
